# 创作与 H3 桥接

用于把用户的创意、剧本或参考表演写成可看懂、可执行的动画行动单元。
主 Skill 负责创作与导演选择；最终 H3 英文稿使用现有 `h3-prompt-writing`，不另造翻译器、槽位注入器或格式编译器。

## 角色外形与表演一起设计

为主要角色确定性格倾向、招牌动作、移动方式及身体允许的夸张变化。特质应改变角色选择的方法或行动结果；可爱造型、耳尾摆动等细节也应服务当下意图。夸张程度服从用户风格，不强制超能力或形变。

首次制作角色素材时，默认用一张可复用综合图容纳三视图、剪影、4—6种表情和3—4种动作，按剧情与实际素材裁减。已有图够用就复用；旧项目不因数量不足而补做或阻塞。表情与姿势的选择应体现角色特点和故事用途：

- 表情让眉眼、嘴形、脸部和头姿共同变化，能看出观察、得意、忍耐或迟疑等不同状态；按角色选择，不固定套通用情绪目录。
- 动作让观众看清重心、支撑、用力方向和身体变化。常用姿势与本片关键姿势可以放在同一张图里；涉及独特能力时先展示其形态。
- 身份图说明稳定外观，表情图说明情绪幅度，动作图说明关键姿势，场景图说明环境。多格图明确是同一角色的不同状态；在镜头中写清所用参考的用途。

静态姿势不表示完整运动时序。步态、接触或复杂形变确有需要时，补能说明该难点的关键姿势与动作先后；不为每镜另做一套参考图。

## 从角色意图写行动

- **行动有目的。** 角色此刻想做成什么，知道什么，为什么选择这个方法？让行为符合故事中的规则；需要寻找、接近或离开时，先完成相应行动。
- **特质进入因果。** 体型、肢体、能力、性格、习惯影响选择、动作和结果；它们可以帮助、妨碍或改变策略，不必总成为笑料。
- **环境提供机会和反馈。** 先让观众认识必要的地点或物件，再让角色利用、绕过或改变它；物件的大小、遮挡、弹性和声音可以参与剧情。
- **移动和局部表演各有动机。** 改变位置、探索或追赶就移动；观察、操作、犹豫和反应可以停下。不要把“原地也灵动”写成全片不走动，也不要为热闹而持续跑跳。
- **变化要可见。** 把理解、误判或情绪变化落在可见的视线、姿态、动作速度、重心和停顿上；关键反应不能藏在道具后，也不能只有抽象心理解释。
- **摄影服务信息。** 先决定观众需要看清什么，再选择景别、机位、运动或切点。可以固定观察，也可以跟随、揭示或切近；不按每句台词切镜，不要求所有镜头运动。

这些是判断依据，不是剧情公式。探索、合作、发现、成功、误会、反转、安静观察都可成立；不强制“失败—再试—更大失败”。
参考作品时提取可描述的表演方法，例如预备动作、耳尾滞后、视线先行、动作后的停顿；原创角色、事件与台词，避免只写“同款风格”。

把目标、角色选择的方法、环境反馈、变化或笑点及结果写进首次剧本与表演分镜，一次收敛。喜剧的铺垫应让观众形成可见预期，偏差和结果在画面中成立；不依赖事后对白解释。以上是写稿内容，融入现有一次联合检查，不另建创作表或复核阶段。

## 以完整动作单元组织

先写连续发生的场面，再决定摄影切点和生成单元。一个单元应让观众读懂一段行动及其反馈，不机械等于一句台词或一个姿势。
写出必要的起态、行动先后、对方反应与落态；时长来自这些内容的可读性，不为凑满时长添动作或拉长停顿。
长片按自然行动边界拆分；下一单元继承已经发生的结果、人物意图、持物和情绪，不从初始状态重演。
拍摄切镜与模型任务分开判断：一个任务可以有完整连续镜，也可以在所选模式与执行工具允许时包含有依据的切镜。

必要空间用自然语言写清，例如“从桌边绕到椅后”“朋友在门口，角色朝声音转头”。
让前中后景、遮挡变化、身体转侧、手臂伸缩、重心与环境接触建立体积和深度，不把位置、yaw、角度或支撑采样账本塞进正文。
轻量人物转身或原地操作也能有空间感；是否位移由行动需要决定。
只在影响理解或同步时给具体时间窗，保留表演呼吸，不把每次眨眼拆成机械时码。
最终单元稿直接从本单元动作内容写成；不要复制旧逐镜模板、换标题后重包成长提示词。

## 角色与原生声音

默认写 H3 原生声画一体：角色在行动中说话、发出非语言声音，拟音与动作同步。
为会发声的角色保留简短声线卡：角色身份、音高/音色、语速及必要的发音特征。跨镜、跨单元复用同一描述；不要每段另换年龄、口音或声线。
`(S1)`、`(S2)` 按**当前生成任务中首次实际发声的顺序**分配，同一任务内跨镜沿用；未发声角色不领 S 号。
跨任务用角色身份和原声线卡复用，并明确映射到当次 S 号；不要把某角色永久绑定 S1 当成声音一致性的保证。
在角色首次发声处用精简身份及固定声线描述建立声源，之后复用标签与必要的演绎提示，不在每句前重贴整段外貌。
实际对白按所选指南写入 `<d>[Language] 原句</d>`，保留原语言和原词；动作、声线和语气写在标签外。Ref2VA 发声角色同时使用对应 `<Subject N>` 与 `(Sx)`。
角色相互听见的对白、观众听见的旁白、内心独白要区分；只有实际画外旁白等适用情形，才按指南要求画中角色闭嘴。
外部音频只在用户提供、明确要求复用或实际方案需要时使用，写清复制/参考关系；不默认另合成 TTS，不凭空定义 `<Audio 1>`。
需要角色可见发声时，不能改写成 `clean visual plate`、`no speech articulation` 或承诺“待后期口型”却没有实际制作步骤。确需后期的例外，明确用户目的、具体工序与交付状态。
声线描述是生成指导，不等于已验证跨任务声音完全一致；如实区分提示词完成与真实生成效果。

## 调用现有 H3 指南

最终写稿时读取 `h3-prompt-writing/SKILL.md`，按实际素材与用户选择确定模式，再读其对应指南；不要为了使用更多标签而改变用户模式。

| 模式 | 读取与处理 |
| --- | --- |
| T2VA / I2VA / FL2VA / L2VA | 读取该 Skill 的 `references/base-en.txt`；沿用三字段、首尾帧对齐指令与相应时序。 |
| Ref2VA | 读取该 Skill 的 `references/ref-en.txt`；沿用六字段、参考标签、保留关系及声源规则。需要共享摄影/对白细则时再读 `base-en.txt`。 |

素材角色要真实：身份参考、首/尾帧、表演视频、时间结构参考、声音参考或声音复用各自说明；身份图不冒充首帧。
参考视频没有实际提供给生成任务时，不写模型正在照该视频表演；把已观察到的方法转成具体动作文字，并注明实际使用的素材。
遵守对应指南的字段名、顺序、标签和时间写法，首个 `[Shot 1]` 不附切点时间，后续 Shot 仅用于实际切镜。
H3 正文用英文，台词、歌词和画面文字保留原语言。原生对白写在主描述字段，环境与动作声音、观众配乐分别进入指南规定的声音字段。
中文执行稿和最终英文来自**同一份已确定的行动、镜头及台词内容**；中文用于核对，英文用于执行，不通过多轮通用稿/逐镜稿/单元稿翻译来叠加内容。
每个动作单元直接交给 H3 Skill 写一次最终稿；已有英文需修改时，就地更新受影响部分并同步中文，不新增编译层。
Ref2VA 指南对生成任务 `detailed_description` 的“通常 350—500 英文词”是正文软建议，不是所有模式或全字段的硬限制。按内容判断，不为凑词重复身份，也不盲删到百词而丢失完整行动和对白。
优先保留可见动作、关键反应、准确对白、必要摄影和参考关系；移除重复外貌、无关禁令、审计说明及后期软件操作文字。

## 确认与交付一致

首次交付前集中读稿一次：行动是否有由来、关键反应是否可见、时长是否容纳动作与完整原句、空间是否能读懂、声源是否稳定。自动格式检查不替代首次创作判断，也不代表模型效果已验证。
HTML 展示、可复制区域、TXT 与实际提交使用**同一份最终英文**，包含对应模式所需的完整字段与指令；HTML 转义仅影响显示，不改变复制出的原文。
不要把几何账本、审核引文或隐藏的第二版提示词混入提交内容；用户改稿后同步所有呈现处。

局部快修以用户指出的问题为输入：就地改受影响动作或描述，同步中英文与报告，自动核对引用、时长及执行参数后提交。保留其余确定内容，不重新研究整片角色、空间或剧情。只在改动实际影响其他段落时说明依赖范围；明确的修复与重生成指令按该范围记录授权，分析或文案请求不扩展为GPU任务。

## 简短输入卡示例

```text
单元：搬运一件易滑的物品，约10秒；具体结果依本故事决定。
起态与目的：两位伙伴在桌旁，要把托盘送到另一侧；角色A尚未注意表面很滑。
角色特质与环境：A行动快，B观察细；托盘、桌沿与窄通道提供实际行动条件。
行动与反馈：A伸手时托盘滑动；B先看到边沿并提醒，A看见后改变握法，两人继续搬运。
可见表演：先看物件再伸手，重心随受力变化；提醒后的眼神和抓握调整留在画面里。
摄影：用能看清两人手部和桌沿的构图，是否移动或切近依信息需要决定。
原句与声音：A先说“Ready?”，B回答“Slowly.”；沿用各自声线卡，角色现场原生发声。
素材与交接：只引用实际可用素材；写清托盘最后由谁持有、下一单元从哪里继续。
```

输入卡只帮助整理必要信息，不要求每个故事出现滑落、提醒、合作或同样的节奏。
